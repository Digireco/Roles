# Roles

This repository includes:

- `massage_interface.py` – a simple massage interface example.
- `btc_rsi_predictor.py` – reads BTC price data from a CSV file and
  outputs an RSI-based buy/sell/hold signal.

Use the sample data in `data/btc_prices_sample.csv` or provide your own
CSV with `date` and `close` columns.

Run `python btc_rsi_predictor.py` to see the latest signal.
